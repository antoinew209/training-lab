# Training Lab

Page du portail d'apprentissage, publiée avec GitHub Pages.

- La page est statique : les quiz, les fiches et la progression sont dans Google Drive, derrière une API Google Apps Script.
- Au premier affichage, la page demande un code d'accès. Il est ensuite mémorisé sur l'appareil.
- Ni le code d'accès ni le jeton de la routine ne figurent dans ce dépôt.
